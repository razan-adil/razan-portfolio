# Remaining authentic project media

Jobs and DClean now have genuine, source-linked interface captures. Road Accident Severity Classification has an exact, attributed public source excerpt. No original leadership-product screenshot is used as evidence of Razan’s redesign.

| Project | Media needed to complete the visual evidence |
| --- | --- |
| Wajeeh AI Agent | A screenshot of the actual Arabic agent interface or a short conversation demonstrating its tone and a public Wadi Jeddah service answer. Exclude private conversations, internal knowledge, system instructions, API keys and account identifiers. |
| Founders Leadership Assessment | Screenshots from **Razan’s redesigned version**: start screen, a question with progress, and the personalized report/results. The public original product cannot substitute for these. |
| Wadi Jeddah Dashboard | A screenshot of the actual Power BI dashboard using approved aggregate or demonstration data. Exclude personal records, registration identifiers, internal-only measures, emails and phone numbers. |
| Road Accident Severity Classification | An existing project report figure, evaluation table or saved model-output plot, if available. Include the original source/report context so the team’s outputs remain separate from Razan’s preprocessing contribution. No evaluation results are invented or reconstructed for the portfolio. |

PNG or JPEG exports at their original resolution are sufficient. Desktop captures are most useful; a mobile interface capture can be added where the original project supports it. No new mockup needs to be invented.
